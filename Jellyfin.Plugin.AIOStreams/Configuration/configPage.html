Jellyio Streams

Connection
Your AIOStreams install URL. Paste it as shown on the addon's "Save & Install" page, e.g. https://stream.example.com/stremio/<uuid>/<token> (a trailing /manifest.json is also accepted). For a public instance without a user config, use the instance root.
Optional parameters appended to every addon request (e.g. api_key=xxx). Leave empty unless your setup requires them.
Library
Folder where the .strm files are generated. Add it as a Jellyfin library of type "Mixed Movies and Shows" (or add Movies / Shows separately). Leave empty to use .
Comma separated catalog ids to sync (as listed by "Test connection"). Leave empty to sync all movie/series catalogs.
Each stream becomes a selectable "version" of the item in Jellyfin. Zero = all streams.
Only the most recent episodes are resolved when set. Zero = all episodes.
Zero = refresh manually only. Restart Jellyfin after changing this value.
