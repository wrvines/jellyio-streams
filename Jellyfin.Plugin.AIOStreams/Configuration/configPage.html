Jellyio Streams

Connection
Your AIOStreams install URL from the addon's "Save & Install" page. A trailing /manifest.json is also accepted. "Test connection" saves the URL before testing, so it cannot be missed.
Optional parameters appended to every addon request. Leave empty unless required.
Library
Folder where the .strm files are generated. Add it as a Jellyfin library of type "Mixed Movies and Shows". Leave empty for the default folder.
Comma separated catalog ids (listed by "Test connection"). Empty = all movie/series catalogs.
Each stream becomes a selectable "version" in Jellyfin. Zero = all streams.
Only the most recent episodes are resolved when set. Zero = all episodes.
Zero = manual only. Restart Jellyfin after changing this value.
